# Bank Marketing Campaign - Investment Subscription Prediction

## Project Overview

In this project, we analyze data from a marketing campaign for investment product subscriptions. The goal is to use customer data to predict whether clients of a bank will subscribe to a term deposit investment or not.

We'll employ machine learning techniques to build predictive models. This notebook documents the complete workflow, including:

- **Data loading** and initial inspection
- **Exploratory data analysis** (EDA)
- **Data preprocessing** and feature engineering
- **Train-test splitting**
- **Model training** with various algorithms
- **Model evaluation** and comparison
- **Performance optimization**

The project compares different classification approaches including Decision Trees and K-Nearest Neighbors (KNN), evaluating their effectiveness in predicting customer investment behavior.

## Key Features

- Comprehensive data exploration and visualization
- Handling of categorical variables through proper encoding
- Comparison of multiple machine learning models
- Evaluation using appropriate metrics for classification problems
- Practical implementation ready for deployment
